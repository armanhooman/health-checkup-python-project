 🩺 Health Check

Health Check is a Python-based desktop health monitoring application designed to collect, manage, analyze, and visualize health-related information through an interactive graphical user interface.

The application provides users with a simple and intuitive environment to enter health data, store records, and generate visual insights using data processing and visualization techniques.

---

 📌 About The Project

Health Check is a desktop application developed using Python that combines GUI development, data management, and data visualization.

The main purpose of this project is to create a lightweight health tracking system where users can record health information, manage their data, and analyze results through graphical reports.

This project demonstrates the practical use of Python libraries for building real-world applications with a focus on user experience, data handling, and visualization.

---

 ✨ Features

 🖥️ Graphical User Interface
- User-friendly desktop interface built with Tkinter
- Interactive input forms for health information
- Custom UI elements and image integration
- Simple and lightweight application design

 📊 Data Visualization
- Generate charts and graphical reports using Matplotlib
- Visual representation of collected health data
- Easier understanding of health-related information

 💾 Data Management
- Store user records using CSV files
- Read and process saved information
- Lightweight local data storage system

 🔢 Data Processing
- Perform numerical operations using NumPy
- Prepare data for analysis and visualization
- Efficient handling of health-related values



 🛠️ Technologies Used

- Python - Main programming language
- Tkinter - Graphical User Interface development
- Matplotlib - Data visualization and chart generation
- NumPy - Numerical calculations and data processing
- Pillow (PIL) - Image processing and UI assets
- CSV - Data storage and file management
